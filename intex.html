🛠️ Supabase Setup

Before using shared features, run the SQL below in Supabase Dashboard → SQL Editor → New query. This creates tables and row-level security policies.

Important: the HTML contains a publishable/anon key, which is intended for browser use. Never put a Supabase service-role/secret key in this file. After running SQL, add your own account UUID to public.gxrv_admins using the Supabase SQL Editor. Instructions are below the SQL.

Make your account an admin

  1. Register through this website and confirm your email if required.
  2. In Supabase Dashboard → Authentication → Users, copy your user's UUID.
  3. Open SQL Editor and run: insert into public.gxrv_admins (user_id) values ('PASTE-YOUR-USER-UUID-HERE'); Replace the example with your UUID. Never share your password or secret keys.
  4. Log out and back in, then open Admin Panel.
